## 🥤 Refrigerante Animado
Refrigerante Animado é uma aplicação interativa e animada desenvolvida com HTML, CSS e JavaScript, que oferece uma experiência visual dinâmica e divertida. A proposta é apresentar diferentes sabores de refrigerante através de uma interface envolvente, com efeitos animados que tornam a navegação mais criativa e atrativa.

## 🚀 Funcionalidades
Interface visual animada e responsiva
Navegação fluida entre sabores
Efeitos visuais com CSS para uma experiência moderna
Interação em tempo real com elementos da página

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3 (animações e transições avançadas)
- JavaScript (dinamismo e interatividade)
